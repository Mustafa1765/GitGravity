Fast-Track: Run the Entire Push Sequence in 1 Click

# 1. Initialize local repository
git init

# 2. Stage all your project files
git add .

# 3. Create your first permanent snapshot
git commit -m "feat: initial commit of my project"

# 4. Set default branch to main
git branch -M main

# 5. Link local folder to your GitHub repository
git remote add origin https://github.com/your-username/hackday-project.git

# 6. Push your code into the main branch!
git push -u origin main
💡 Paste this into your terminal (VS Code / Antigravity terminal) to push your whole project in 5 seconds!

Core Concept

Git vs GitHub: The #1 Student Confusion

Many beginners think Git and GitHub are the same thing. They aren't! Here's the clearest explanation you will ever read.

Offline Tool
⚡

Git

The Version Control Software

Real-Life Analogy: Think of Git as a high-tech camera installed on your laptop that takes snapshots of your code whenever you ask.
  • ✅ Works 100% offline without internet connection
  • ✅ Installed on your local machine / command terminal
  • ✅ Tracks line-by-line history and changes in code
  • ✅ Created by Linus Torvalds in 2005 for Linux
  • ❌ Has no website, no public user profile, and no cloud hosting by itself
VS
Cloud Platform
🐙

GitHub

The Cloud Sharing & Collaboration Website

Real-Life Analogy: Think of GitHub as Instagram or Google Drive for code where you upload your photo albums to share with the world.
  • ✅ A website (github.com) owned by Microsoft
  • ✅ Hosts your remote Git repositories online
  • ✅ Enables Pull Requests, Code Reviews, and Hacktoberfest badges
  • ✅ Issue trackers, GitHub Actions (CI/CD), and Project Boards
  • ⚠️ Uses Git under the hood to manage the repositories
